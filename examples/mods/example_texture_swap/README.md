# example_texture_swap

Replaces two built-in brush textures everywhere: the campaign, the lounge, every custom map. Copy this folder into your **mods** folder and restart the game.

| File | Replaces |
|---|---|
| `replace/CNAL11_1.png` | A concrete floor texture (the example maps use it) |
| `replace/BKAP1_1.png` | A brick wall texture (the example maps use it) |

Both are 256x256, the same size as the originals. Match the size or your texture gets stretched.

Want it just for yourself, no mod? Put the PNGs in the `replace` folder next to `mods` instead (`mod path` shows it).

Cosmetic, so leaderboards and achievements stay on. Run `mod disable example_texture_swap` to get the original walls back.
