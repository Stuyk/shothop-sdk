# example_weapon_sounds

Replaces built-in sounds. Copy this folder into your **mods** folder and restart the game. Fire the shotgun and revolver.

| File | Replaces |
|---|---|
| `replace/shotgun/sfx_shotgun_shot_a.ogg` to `_e.ogg` | The five shotgun blasts (the game picks one at random) |
| `replace/revolver/sfx_revolver_a.ogg` to `_c.ogg` | The three revolver shots |

The rule: **same file name as the built-in sound, `.ogg`, inside `replace/`.** Subfolders are only for keeping things tidy.

Find other names with `mod sounds`, like `mod sounds reload` or `mod sounds footstep`.

No maps, no tuning, so leaderboards and achievements stay on.
