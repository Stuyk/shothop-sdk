# example_music

Replaces the in-level music with the mod's own track. Copy this folder into your **mods** folder.

- `music/example_music_loop.ogg` is a 60 second loop at -14 LUFS.
- `mod.json` sets `"replace_music": true`, so it's the only track in levels. Leave that out and it joins the game's playlist instead.

No maps. Play any level to hear it. Run `mod disable example_music` to get the soundtrack back.
