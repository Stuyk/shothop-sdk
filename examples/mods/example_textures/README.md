# example_textures

A map built from the mod's own brush textures. Copy this folder into your **mods** folder.

| File | Surface (from the prefix) | Used on |
|---|---|---|
| `textures/CNEXAMPLE_FLOOR.png` | `CN` concrete | Floor |
| `textures/MTEXAMPLE_PANEL.png` | `MT` metal | Walls |
| `textures/WDEXAMPLE_CRATE.png` | `WD` wood | The crate in the middle |

Shoot each one. Different sparks, sounds and decals.

To edit the map in TrenchBroom, copy the three PNGs into the SDK's `textures/` folder first so TrenchBroom can show them.
